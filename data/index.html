Data

This site uses publicly available data provided by GitHub, OpenAI and Anthropic. This data get stored into a GitHub Gist, where a entry is created every 15-ish minutes. These entries get stored for 30 days and are displayed in a graph.

Contradicting data

When the site is unable to fetch data (and thus does not show enough data points), the impact of outages become hard to measure. Furthermore, the status message (written by humans) may differ from the automated status updates.

Graph

The graph shows the number of pull requests created on GitHub in the last 15 minutes of the listed time. Since GitHub is the largest developer platform on earth, this metric can be interpreted as how active developers are at any given moment worldwide. This metric is shown alongside the downtime of two major AI providers, OpenAI (ChatGPT) and Anthropic (Claude).

Why?

If the theory of me and many others is correct, any time a AI system is down, you should see a decrease in made pull requests shortly after. This is fun, because it shows our level of independence dying with every passing second.
